How priority is decided (transparent rule)
  • Litres above norm: +2 if total is 300 L or more, or any single exception is 150 L or more; +1 if total is 150 L or more.
  • Repeat exceptions: +2 for 3 or more exceptions; +1 for 2 exceptions.
  • Sudden increase: +1 if the latest exception is at least 1.3 times the average of the earlier ones.
  • Continuous across shifts: +1 if two exceptions fall in back-to-back shifts (A→B, B→C, C→next day A).
  • Open for several days: +1 if any exception is still Pending / Under Inspection for 3 or more days.
  • Priority: Critical = 6–7 points, High = 4–5, Medium = 2–3, Low = 0–1.

      Forecast & planning – next month

      Diesel Forecast, Operator Counselling and Trip Capacity

      Uses all records in the data. It does not follow the filters above.

      Assumption: the records have no trip counts, so "trips per shift at norm" is a made-up planning number you can change. Activity 100% means the same number of recorded shifts as the last 30 days.

      How the forecast works (plain English)
      • Step 1: for each machine, work out how much diesel it used compared with its norm (for example 120% = 20% above norm).
      • Step 2: recent records count more. A record's weight halves every 10 days.
      • Step 3: shifts next month = shifts recorded in the last 30 days, scaled to the days in next month and to the activity % above.
      • Expected diesel = shifts × norm × weighted usage %.
      • Best case: the exceptions are fixed and each machine runs at or below norm. Worst case: the latest 3 records show the new normal.
      • Trips: with the same approved diesel (norm), a machine using 120% of norm can only do about 1/1.2 of the planned trips. The rest are “lost trips”.
      • This is a simple, explainable model on thin sample data. Treat it as guidance, not a promise.
